Cancellation restores the committed tab, the rail clamps at both ends, right-to-left layout reverses physical movement, and ordinary tab taps remain available.

Events are queued, including repeated identical messages, and survive backgrounding within the current app process. Text wraps at large sizes, TalkBack receives the full message, and reduced motion uses a still capsule. Android reminder alerts retain the notification shade and its actions.
- Preserve Room data and all existing provider, export, reminder, and notification capabilities. No fabricated counters, connectivity badges, avatars, sample tasks, or microphone activity.
- Voice uses Android SpeechRecognizer, runtime permission, partial/final transcripts, explicit errors, and lifecycle cleanup. Each session releases its recognizer on every terminal path, ignores old callbacks, and can recover once from a temporarily busy service. It never saves a reminder automatically.

Validation uses the user's cloud build: run behavior tests and Compose screenshots, inspect narrow/large-text layouts, then build the APK there. Do not compile an APK locally. A screenshot cannot verify a physical microphone or OEM alarm delivery; these require device checks.
