# FlowMind — quiet utility

The supplied HTML is a reference draft, not an implementation directive. The Pinterest references set the direction: charcoal surfaces, generous negative space, clear white type, and small instrument-like details. The video contributes the moving selection treatment; the navigation image contributes the cool glass rim.

- Background #090A0C. Surface #18191D. Chalk #F3F2EF. Secondary text #A5A6AF. Ice #D4E5F5 is reserved for selections and progress.
- 24 dp page gutters, 24–32 dp between sections, 48 dp minimum actions. Let titles wrap; support large text and short screens with scrolling.
- Today prioritizes capture and the next actual reminder. Schedule filters timestamps, not decorative time strings. Done uses completion dates. Settings progressively discloses optional AI configuration.
- Native Compose throughout. Tabs switch in place with a quick 160 ms dissolve; the fixed header and spring-driven glass dock maintain continuity. The floating dock samples the scrolling content for blur on Android 12+ and adds a restrained glass rim. Older Android uses a readable translucent surface.
- Two quiet currents and a travelling highlight sit inside the existing next-reminder card. A soft halo breathes around the real daily progress ring, using the same eight-second clock. These details are decorative, with no invented activity metrics or rotating progress indicator. The clock runs only while that card is visible and the app is resumed and focused; disabling system animations leaves a still composition. Navigation icons settle with a small spring as their selection changes.
- All in-app feedback uses one capsule centered horizontally at the top, 12 dp below the safe status-bar/cutout inset: action icon appears, expands to reveal the complete message, holds for reading, compacts, then travels upward out of view. The capsule's appearance and sequence are preserved; its exit distance uses its measured height and top offset. Events are queued, including repeated identical messages, and survive backgrounding within the current app process. Text wraps at large sizes, TalkBack receives the full message, and reduced motion uses a still capsule. Android reminder alerts retain the notification shade and its actions.
- Preserve Room data and all existing provider, export, reminder, and notification capabilities. No fabricated counters, connectivity badges, avatars, sample tasks, or microphone activity.
- Voice uses Android SpeechRecognizer, runtime permission, partial/final transcripts, explicit errors, and lifecycle cleanup. Each session releases its recognizer on every terminal path, ignores old callbacks, and can recover once from a temporarily busy service. It never saves a reminder automatically.

Validation uses the user's cloud build: run behavior tests and Compose screenshots, inspect narrow/large-text layouts, then build the APK there. Do not compile an APK locally. A screenshot cannot verify a physical microphone or OEM alarm delivery; these require device checks.

Android implementation references: [SpeechRecognizer lifecycle and service visibility](https://developer.android.com/reference/android/speech/SpeechRecognizer) and [Compose graphics layers](https://developer.android.com/develop/ui/compose/graphics/draw/modifiers).
